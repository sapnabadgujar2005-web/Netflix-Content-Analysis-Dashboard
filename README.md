Netflix Content Analysis Dashboard

Project Overview

This project presents an interactive Netflix Content Analysis Dashboard created using Microsoft Power BI. It explores Netflix movies and TV shows to identify content distribution patterns and trends.

Objectives

- Analyze the distribution of Movies and TV Shows.
- Explore content ratings and genres.
- Identify countries contributing Netflix content.
- Examine content trends by release year and content addition date.

Tools Used

- Microsoft Power BI
- Power Query
- Data Visualization

Dashboard Features

- Key Performance Indicators (KPIs)
- Movies vs. TV Shows analysis
- Genre analysis
- Content ratings analysis
- Top countries by content
- Content addition trends
- Release year analysis

Project Files

- Power BI dashboard (".pbix")
- Dashboard screenshot (".png"), if included

Dataset

The dashboard uses a Netflix titles dataset obtained from Kaggle. The original dataset source and license have not yet been verified. The dataset file is not included in this repository.
